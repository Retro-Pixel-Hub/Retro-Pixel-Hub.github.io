HOW THE VILLAGES ARE MADE

A two-pass Wave Function Collapse lays out roads first, then fills every lot with houses, trees and flowers — following socket rules so it always looks designed.

1 · LAYOUT PASS

Only road pieces exist: straights, corners, T-junctions and crossings. No dead-end piece exists, so every road loops or leaves the map.

2 · DETAIL PASS

Roads are locked in. Each empty lot collapses into grass, flowers, trees or a cottage. Lowest-entropy cell first, weighted random choice, then constraints ripple outward.

3 · SOCKET RULES

Each tile edge has a socket. A front door only fits next to the side of a road, so every house faces a street.
